# QA Automation – Playwright Examples

## Overview
This repository contains small automated UI testing examples created using Playwright. The purpose of this project is to demonstrate basic browser automation skills suitable for junior or entry-level QA roles.

---

## Technology Used
- Playwright
- JavaScript
- Node.js

---

## Automated Scenarios

### Login Test
- Navigates to a public demo login page
- Enters valid credentials
- Verifies successful login message

### Checkbox Test
- Navigates to a checkbox demo page
- Verifies checkbox count
- Toggles checkbox states and validates behaviour
